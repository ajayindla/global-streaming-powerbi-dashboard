# 🎬 Global Streaming Analytics Dashboard

## Overview
A 4-tab interactive Power BI dashboard analyzing global streaming 
platform performance across 10 platforms, 109 countries (2016–2026).

## Tools & Technologies
- Power BI Desktop
- DAX (10+ measures)
- Power Query (ETL)
- Star Schema Data Modeling
- Excel (Data Source)

## Dashboard Tabs
- Dashboard Overview — Executive summary with all KPIs
- Platform Overview — Subscriber growth & market share
- Content Performance — Top shows, movies & IMDb ratings
- Global Reach — World map & country-level analysis

## Key Metrics
- 24,352 rows of data
- 10 streaming platforms
- 109 countries
- 11 years (2016–2026)
- Subscribers, Revenue, ARPU, Churn, MAU, YoY Growth
